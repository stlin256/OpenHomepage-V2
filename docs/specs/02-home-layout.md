# 主页布局方案（细化项 #2）

> 状态：✅ 已确认（2026-08-22）——**B. 杂志网格**（12 列不对称跨栏）；字体 **Inter + 思源黑体子集**，代码 JetBrains Mono。

## 候选方案

### A. 经典双栏（科研主页风）

```
┌─────────────────────────────────────────┐
│ nav(tab)                                │
│ ┌──────────┬──────────────────────────┐ │
│ │          │  简介正文 markdown        │ │
│ │  头像    │                          │ │
│ │  姓名    │──────────────            │ │
│ │  tagline │  GitHub 贡献图           │ │
│ │  链接行  │  pin 项目卡片 (2列)       │ │
│ │ (sticky) │  RSS 卡片流              │ │
│ └──────────┴──────────────────────────┘ │
└─────────────────────────────────────────┘
```
左栏窄（约 1/4）sticky 跟随，右栏内容流。优点：最像科研人员主页；缺点：杂志感弱。

### B. 杂志网格（不对称跨栏）⭐ 推荐

```
┌─────────────────────────────────────────┐
│ nav(tab)                                │
│  ┌───────────────────┐  ┌────────────┐  │
│  │ 大标题(姓名/简介跨2栏)│  头像(大图块)│  │   ← 12列网格: 7+5 跨栏
│  └───────────────────┘  └────────────┘  │
│  ┌────────────────────────────────────┐ │
│  │ GitHub 贡献图 (通栏)                │ │
│  └────────────────────────────────────┘ │
│  ┌──────────┐ ┌──────────┐ ┌─────────┐  │
│  │ pin 卡片  │ │ pin 卡片  │ │ pin 卡片 │  │   ← 卡片错落网格
│  └──────────┘ └──────────┘ └─────────┘  │
│  ┌────────────────────────────────────┐ │
│  │ RSS 卡片流                          │ │
│  └────────────────────────────────────┘ │
└─────────────────────────────────────────┘
```
12 列网格，简介与头像不对称跨栏（如 7/5），区块间大留白、细分割线。优点：杂志感强；缺点：实现略复杂。

### C. 居中单栏（极简）

```
┌──────────────────┐
│   nav(tab)       │
│   头像(圆形小图)  │
│   姓名 / tagline │
│   简介正文        │
│   ─────────      │
│   GitHub / RSS…  │
└──────────────────┘
```
内容区约 640-720px 居中。优点：最简单最克制；缺点：不符合"杂志化"要求。

三案移动端均退化为单列流。

## 字体配对

自托管 webfont：拉丁 **Inter** + 中文 **思源黑体（Noto Sans SC）子集化**（只打包用到的字重与字符子集，控制体积）；等宽用 **JetBrains Mono**（代码块）。
