# 国际化 i18n 设计（细化项 #11）

> 状态：✅ 已确认（2026-08-22）。范围：站点页面多语言（可选启用）、编辑器界面 i18n、CI 文案双语。机制本身语言无关（目录名即语言码）；内置 UI 文案与示例数据随附 zh / en / ja / fr 四种语言，编辑器界面与 CI 文案仍为 zh / en。

## 1. 页面多语言

### 语言声明（子目录分语言）

```
data/pages/
├── zh/                # 中文页面目录
│   ├── index.md       # 主页（slug 为 /）
│   └── research.md
└── en/                # 英文页面目录
    ├── index.md
    └── research.md
```

- **目录名即语言声明**（`zh` / `en`），frontmatter 无需 `lang` 字段。
- **自动启用**：检测到 `pages/` 下存在 ≥2 个语言目录 → 整站 i18n 自动开启；只有一个语言目录 = 单语言站，零 i18n 开销。
- `site.yaml site.language` 决定默认语言（影响无前缀 URL，见下）。

### 缺失回退

- 回退链：**当前语言 → 英文（en）→ 站点默认语言 → 任一可用版本**。
- 回退时 URL 保持所访问语言前缀，内容按命中的真实版本完整渲染；**不再显示语言降级提示条**，导航不断链。

### URL 与导航

- 默认语言无前缀：`/research`；其他语言带前缀：`/en/research`。
- 正文 Markdown、编辑区块和流式内容里的站内页面链接可写语言无关路径（如 `/research`）；构建时按当前路由改写为 `/en/research` 等路径。静态资源、外链、锚点和未识别路径保持原样。
- i18n 启用后页顶工具区出现语言切换器：**翻译图标小方块按钮**（与主题按钮同款风格），hover 或点击弹出语言选项菜单（点别处 / Esc 关闭），**仅当当前页面存在真实的另一语言版本时显示**；回退渲染的页面不显示（避免在两种 URL 语言下跳转自相同内容）。菜单内**当前语言置顶**，其余保持站点语言顺序（`orderLangMenu`，仅显示顺序，hreflang 输出不受影响）。
- 语言选择写入 `localStorage`，客户端内容交换同步更新 URL。交换用的目标页 HTML 来自共享内存缓存（`src/scripts/page-cache.ts`）：空闲预取会提前下载语言菜单中的备选语言页面，已交换过的页面再次切换直接命中缓存；加载遮罩延迟 150ms 出现，语言切换遮罩可见并至少持续 420ms（右上语言菜单保持在遮罩上方，用于呈现菜单 FLIP 动画）；新页动画与计时（通知横幅、流式输出等）等遮罩结束后才启动。刷新或直开 URL 时，`<head>` 内联脚本会在首帧绘制前比较 `data-route-lang` 与偏好并 `location.replace` 到目标语言路径，因此不会先渲染另一种语言。
- `<html lang>`、hreflang 标签自动输出。实现注记（M4a）：`<html lang>` 取**实际内容语言**（回退页面为回退后的语言），hreflang 只输出该 slug 真实存在的语言版本并附 `x-default`（指向默认语言版本）。

### 流式区块与配置文案

- 流式内容文件同按语言分目录：`streaming/zh/welcome.md` + `streaming/en/welcome.md`，按当前页面语言自动选文件，缺变体按回退链（en 优先）。
- site.yaml / rss.yaml 中的展示文案（区块标题、tagline 等）：**字段支持双语映射**：

```yaml
profile:
  tagline:
    zh: "博士研究生"
    en: "PhD candidate"
rss:
  block_title: { zh: "最近在读", en: "Reading" }
```

字段写纯字符串 = 所有语言通用；写多语言映射（键为语言码，数量不限，如 `{zh, en}`）= 按语言取值，缺 key 回退 en → 站点默认语言 → 任一可用值。

## 2. 编辑器 i18n

- 编辑器界面文案全部走 i18n 字典（zh / en），顶栏语言切换，选择存 localStorage，默认跟随浏览器语言。
- 编辑多语言页面：页面列表按语言目录分组（`zh / en` 分组下挂各页面）；「新建页面」向导与「创建另一语言版」弹窗的语言下拉列出已有语言 + 常用语言（选中未建目录的常用语言即新建语言目录），已拥有该页面的语言不列出。

## 3. CI 邮件/通知文案

- GitHub 失败邮件本身不可定制（官方英文模板）。
- 我们产出的所有 workflow 注解（error/warning/summary）**中英双语并列**输出，例如：

```
::error::在线 data 源失效且无历史快照，无法构建 / Online data source failed and no snapshot available; build aborted.
```
